## 2. TARGET VENUE PROFILE (who gets the offer)
Qualifying criteria — a venue gets outreach only if it matches:
1. **Has 1-4 screens already** (or an obvious screen spot) — no hardware selling, content only.
2. **Menu of 10-35 items** — fits the clip_spec template directly.
3. **Visibly static today** — printed board, basic slideshow, or TV off. (A venue already running good motion content is a harder sale.)
4. **Independent or small chain (≤3 locations)** — chains need the multi-location tier (different pitch, longer cycle).
5. **Owner-operated** — the person who can say yes is reachable by walk-in/DM.

**Priority venue types (all 4 cities):** burger/grill bars, bakeries with display cases, kebab/Balkan grills (diaspora wedge), cafés with food menus, bubble-tea/dessert shops.

## 3. THE OUTREACH SEQUENCE (per venue — GDPR-compliant, low-volume, high-touch)
Volume plan: **10 venues per city = 40 touches total** (G1 gate = ≥1 paying client from 40).

| Step | Action | Cost | Channel |
|---|---|---|---|
| 1 | Walk-in or Instagram DM to qualifying venue; short pitch + ask for the menu (or photograph the printed menu on-site) | €0 | In-person / DM |
| 2 | Produce **ONE free 6-10s clip** of THEIR actual bestselling item on a neutral cinematic stage (no branding yet — watermark "VAST sample") | ~$0.17-0.50 GPU | Requires GPU approval (§8) |
| 3 | Return within 48h: play the sample on a phone/tablet to the owner; pitch the CORE package ($800-1,500 + $50-150/mo) | €0 | In-person |
| 4 | Yes → intake form (§4) → full package production → deploy | $10-25 GPU | Pipeline |
| 5 | No → ask one question ("what would it need to show?"), log the answer in the tracker (§6) | €0 | — |

**Why walk-in/DM-first, not email:** Germany and France restrict cold B2B email (Germany's UWG practice is strict; France requires honoring opt-outs immediately). Walk-in + Instagram DM to a business's public account is lower-friction and legally cleaner. Log every contact basis in the tracker (GDPR accountability).

**The €0.17 demo is the spearhead:** a clip of the venue's *own* food costs ~$0.17 in GPU and ~30-60 min of pipeline time. Traditional studios cannot demo at this cost. This is the structural advantage.

## 4. CLIENT INTAKE FORM (fill on first "yes" — phone or paper)
```
1. Venue name, address, contact person, phone/Instagram
2. Screens: how many, sizes, orientation (landscape/portrait), mounted where?
3. Player: existing TV box / smart-TV browser / nothing yet?
4. Full menu: items, prices, categories (or photograph the printed menu)
5. Signature items (top 3-5 sellers) — these get the magic-reveal clips first
6. Brand: logo files, colors, any existing mascot/character?
7. Mascot preference: (a) keep it food-only, no mascot  (b) suggest 3 mascot concepts for us to pick
8. Promo/combo items to feature in the rotating promo panel
9. Day/night trade: does the venue look different after dark? (neon? candles?)
10. Hosting: client VPS/USB stick, or VAST-hosted container (adds monthly fee)
11. Price editing: who updates prices, and how often? (drives Google-Sheet vs admin choice)
12. Languages on the board: DE/EN? FR/EN? NL/FR? MK as well?
13. Timeline: when do they want it live?
14. Consent: venue confirms right to use their menu/brand assets; VAST watermark or none?
```

## 7. FREE-SAMPLE PRODUCTION RUNBOOK (executes AFTER GPU approval)
Per sample (~$0.17-0.50 each):
1. Build ONE photoreal keyframe of the venue's signature item: neutral cinematic stage, food hero framing (template from `abracadabra-menu/clip_specification.json` keyframe_prompt pattern — proven).
2. LTX-2.5 continuation prompt per the **67 §2 structure (2026-11-20 verified standard)**: Camera → Scene → ONE action → held ending → style anchors. Positive wording only — artifact negatives (`watermark, text, logo`) are the ONLY negatives allowed; never write "no X" (it fires X). (Template: the patched `ltx_prompt` fields in the same file — 35/35 compliant as of 2026-11-21.)
3. Render 1 clip, 121 frames (8n+1), 1280×720, 8 steps, CFG 1.0. **Start-frame strength 0.7 default** (0.5 for more motion; raise toward 0.85 if the model re-dreams the start frame). Watermark "VAST — sample".
4. Copy home, sha256-verify, destroy the box (per standing destroy rule).
5. Deliver to owner on phone/tablet within 48h of first contact.

Batch option: once ≥5 venues in one city say yes to a sample, render all samples on ONE rental session (one box, sequential clips) to amortize provisioning — total ~$1-3 for 5-10 samples.

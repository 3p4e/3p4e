# Bossfight Keyframe Prompt Pack — 50 shots × 2 frames = 100 keyframes

**For use in Grok / Gemini / any image model app.**

## How to use this pack

1. Each shot has a START frame and an END frame. Generate both.
2. **If the app supports image references:** attach the face refs listed and
   instruct it to KEEP THOSE EXACT FACES. Ref files local at:
   `media/dhpf_refs/ddface_a.jpg`, `ddface_b.jpg`, `azface_a.jpg`, `azface_b.jpg`
3. **If the app does NOT support refs:** it will invent faces. The result is usable
   ONLY as a look/composition/blocking draft, never as a final film keyframe.
4. Settings to match: 1280×720 landscape, 50 steps, cfg ~4.0.

## The blocking law (already woven into every prompt below)

```
3/4 side camera, low 24mm, NEVER frontal to a fight.
DD + Azulon: torso and head oriented AT the boss, weapons to the boss.
Boss: faces them, centre-right, silhouette readable.
Sightlines converge. No body faces the lens. No poster pose.
```
